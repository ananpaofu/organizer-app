# 收纳小管家（手机版）

一款记录物品、到期提醒、定位标签一键查找的收纳管理 Web App。

## 功能

- 物品录入（支持拍照）、搜索、分类筛选
- 保质期到期提醒与环形进度
- 自定义收纳地图（地点格子）
- 设备联动：定位标签一键查找、离位提醒
- 社区动态与聊天
- 高德地图接入（需在 App 内配置自己的 Key）
- 支持安装到手机桌面、离线访问（PWA）

## 本地运行

直接用任意静态服务器打开本目录即可，例如：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

> 直接双击 `index.html` 用 `file://` 打开也能看到界面，但 Service Worker 和定位等能力需要 `http(s)` 环境才生效。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `organizer-app`）。
2. 把本目录下的所有文件上传到仓库根目录。
3. 进入仓库 **Settings → Pages**，Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等待几分钟后，访问 `https://你的用户名.github.io/仓库名/` 即可。

## 高德地图（可选）

App 内「联动 → 设备联动说明 → 查看真实中国地图接入方案 → 配置高德 Key」中，填入在高德开放平台申请的 Web 端 (JS API) Key 与安全密钥即可启用真实地图。留空时使用内置示意地图，不影响其他功能。

## 说明

- 数据保存在浏览器本地（localStorage），不上传服务器。
- 本项目仅包含手机版，桌面版本未包含在内。
